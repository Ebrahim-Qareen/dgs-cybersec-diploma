Module 1

Foundation Phase

64 hours · 16 sessions · 24 labs · 1 project

Computer, OS, networking & security fundamentals

Topic 1

Computer, Operating Systems & Security Fundamentals

How a machine boots and runs, virtualization, the CIA triad, authentication and authorization, and the language security teams use every day.

Topic 2

Windows Internals & Linux Fundamentals

Processes, services, the registry and privileges on Windows; the filesystem, users, permissions and services on Linux.

Topic 3

Networking Fundamentals & Protocol Analysis

IP addressing and subnetting, the OSI and TCP/IP models, encapsulation, and reading DNS, HTTP, SMB and RDP on the wire.

Topic 4

PowerShell & Bash for Security Operations

The commands an analyst actually uses: querying processes, services and event logs, and automating repetitive triage.

Topic 5

Active Directory & Authentication Fundamentals

Domains, objects and group policy; how NTLM, Kerberos and LDAP authenticate a user and what each writes to the logs.

Topic 6

Windows, Linux & Web Log Analysis

The Event IDs that matter, syslog and journald, and web server access and error logs — where the evidence lives.

Topic 7

Web Technologies & Common Attack Awareness

HTTP end to end, the modern web stack, and the OWASP Top 10 seen from the defender's side.

Topic 8

Foundation Investigation & Capstone

Your first full investigation across Windows, Linux and web evidence, written up as a report.

Tools you meet here
VMwareWindowsLinuxPowerShellBashWiresharkEvent ViewerAD DS
You leave able to
Read a Windows event, a Linux log line and a packet capture and say what happened; explain how Kerberos and NTLM log a login; build and run your own lab.
Module 2

Security Operations & SIEM

40 hours · 10 sessions · 18 labs · 1 project

SOC workflow, triage, Splunk, Wazuh, Sigma

Topic 1

SOC Operations, Alert Triage & Incident Handling

How a security operations centre runs, how an alert becomes a case, true positive versus false positive, severity and escalation, case work in TheHive.

Topic 2

Log Analysis & Event Correlation

Reconstructing a process tree from Sysmon, and correlating one event across endpoint, network and web sources.

Topic 3

Splunk Investigation & Detection Development

Indexing and sourcetypes, SPL from first search to statistics and dashboards, investigating a real attack dataset.

Topic 4

Wazuh Deployment, Monitoring & Detection

Agents, decoders, rules and alerts — building the pipeline end to end and testing your own detections against it.

Topic 5

Sigma Rules & Cross-SIEM Detection Engineering

Writing one rule once and running it everywhere: Sigma syntax, conversion to SPL and Wazuh, and validating both.

Tools you meet here
TheHiveSysmonSplunkWazuhSigma
You leave able to
Triage an alert to a defensible verdict, open and close a case in TheHive, search both Splunk and Wazuh, and write one Sigma rule that runs on both.
Module 3

Detection Engineering

32 hours · 8 sessions · 14 labs · 1 project

Attack analysis & detection development

Topic 1

Detection Engineering Fundamentals

The detection lifecycle, what makes rule logic good or fragile, and how coverage is measured.

Topic 2

Endpoint Attacks & Detection Techniques

Execution, persistence and defence evasion simulated in the lab, each traced back to its Sysmon and event-log evidence.

Topic 3

Active Directory Attacks & Detection

Credential access and lateral movement inside a domain, and the authentication events that expose them.

Topic 4

Network Attacks & Detection Techniques

Scanning, interception and exfiltration patterns as they appear in packets, firewall logs and IDS alerts.

Topic 5

Web Attacks & Detection Techniques

Injection, cross-site scripting and traversal — what each leaves behind in a web server log.

Topic 6

Detection Use Cases & Correlation Logic

Turning a threat into a documented use case, and writing logic that needs more than one event to fire.

Topic 7

Alert Tuning & False Positive Reduction

Making a noisy rule useful with evidence before and after, and proving you did not break the detection.

Topic 8

Detection Development Project

Build, test and document a set of working detections across both SIEM platforms.

Tools you meet here
Atomic Red TeamNmapDVWASuricatasigma-cli
You leave able to
Simulate an endpoint, AD, network or web attack in the lab, find its evidence, write the detection that catches it, and tune it until it stays quiet on normal traffic.
Module 4

Threat Hunting & Intelligence

24 hours · 6 sessions · 10 labs · 1 project

Hunting methodology, ATT&CK, CTI

Topic 1

Threat Hunting Methodology

Hypothesis, data, query, finding — hunting as a repeatable method rather than a search for luck.

Topic 2

MITRE ATT&CK & Adversary Behaviors

Tactics, techniques and procedures, the Pyramid of Pain, ATT&CK Navigator and D3FEND countermeasures.

Topic 3

Endpoint, Network & Log-Based Hunting

Topic 4

IOC Hunting & Threat Intelligence

Indicator types and their lifetime, enrichment with VirusTotal and OTX, and turning intel into watchlists.

Topic 5

Threat Intelligence Platforms & Enrichment

MISP events and attributes, feed quality, and wiring enrichment into the triage workflow.

Topic 6

Threat Hunting Investigation Project

Run a full hunt from a published threat report and document what you found.

Tools you meet here
ATT&CK NavigatorD3FENDVirusTotalOTXMISP

Module 5

Incident Response Lifecycle

Static Malware Analysis & IOC Extraction
