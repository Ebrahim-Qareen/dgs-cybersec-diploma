# DGS Academy — Cyber Security Diploma

**6-Month Intensive Professional Program · Blue Team / Security Operations Track**

A hands-on, career-focused diploma that trains you to monitor, detect, investigate and respond to real cyber threats — built entirely around practical labs and real investigations.

| 192 | 48 | 79 | 6 |
|---|---|---|---|
| Training hours | Live sessions | Practical labs | Real projects |

## Modules

1. **Foundation Phase** — computer, operating systems, networking, PowerShell/Bash, Active Directory, log analysis, web technologies
2. **Security Operations & SIEM** — SOC workflow, alert triage, event correlation, Splunk, Wazuh, Sigma
3. **Attack Analysis & Detection Engineering** — endpoint, AD, network and web attacks with their detections, use cases, alert tuning
4. **Threat Hunting & Threat Intelligence** — hunting methodology, MITRE ATT&CK, IOC hunting, TI platforms
5. **Incident Response & Digital Forensics** — IR lifecycle, triage and containment, live response, memory forensics, Windows artifacts
6. **Malware Analysis for Analysts** — static and dynamic triage, IOC extraction

## Tools

Splunk · Wazuh · Sigma · TheHive · Sysmon · Windows Event Viewer · Linux audit logs · MITRE ATT&CK Navigator · D3FEND · MISP · AlienVault OTX · VirusTotal · Volatility 3 · Autopsy · PowerShell · Bash · Python
