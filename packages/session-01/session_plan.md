# Session 01 — Session Plan (instructor-private)

**Live session L01** · Module 1 · Topics **M1.1** Computer, OS & Security Fundamentals + **M1.2a** Windows Internals.
Student page: `docs/session-01/index.html`. Labs: LAB-L01-A/B (in class), C/D (task), E (self).

## Objectives
Students can: name the CIA pillar each attack breaks · use vulnerability/threat/exploit/risk correctly · read a process tree and spot a bad parent→child · recall the six Security Event IDs · locate persistence · run first triage on a Windows endpoint.

## Timing (360 min)
| Block | Min | Content |
|---|---|---|
| Recap + setup check | 20 | Confirm every VM boots, snapshot taken |
| Teach A — Security foundations | 70 | CIA (bank analogy) · V→T→E→R · malware/hackers · SOC |
| Break | 15 | |
| Guided Lab A | 70 | LAB-L01-A verify VM + LAB-L01-B process inspection |
| Teach B — Windows internals | 65 | arch stack · process tree · persistence · Event IDs · attack↔detection |
| Break | 15 | |
| Independent Lab B + Challenge | 80 | Finish LAB-L01-B alone; run the first-triage challenge |
| Wrap-up | 25 | Cheat sheet, at-home task handout, next-session hook |

Hands-on = 150/280 teaching minutes (≥50%). Setup pack is a prerequisite, not a lesson (no installs in class).

## Dependencies
Teaches local accounts only (AD deferred to L04). Event IDs introduced here anchor L05 and L07 — taught once. Nothing re-taught later.
