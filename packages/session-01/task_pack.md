# Session 01 — At-home Task Pack (free)

Do these after class on the same VM. Bring notes to L02. All free.

## Task 1 — Persistence hunt (maps LAB-L01-C)
Open **Autoruns**, tick *Hide Microsoft entries*, review unsigned start-up items.
**Deliver:** table of each unsigned entry — name, location (Run key / Startup / Task / Service), safe or suspicious, why.
*Expected:* on the seeded image, one planted entry (e.g. `update.exe` in `C:\Users\Public`) with no publisher.

## Task 2 — Accounts & UAC (maps LAB-L01-D)
`net user`, `net localgroup administrators`, then trigger a UAC prompt.
**Deliver:** who is admin; one line on when Windows shows a consent vs a credential prompt.

## Task 3 — Free practice room
Complete **TryHackMe — Windows Fundamentals 1** (free).
**Deliver:** the Task Manager keyboard shortcut, and one thing new to you.
